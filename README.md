# Lunar & Martian Seismic Activity Prediction

## Overview
This project demonstrates predicting seismic activity on the Moon and Mars using **simulated seismometer data**. The goal is to show how **signal processing** and **LSTM deep learning** can forecast seismic events.

## Features
- Simulated lunar and martian seismic signals
- Data normalization and preprocessing
- LSTM model training for time-series forecasting
- Visualization of predicted vs actual seismic signals
- Optional detection of high amplitude seismic events

## Requirements
- Python 3.8+
- numpy
- matplotlib
- scikit-learn
- tensorflow

## Usage
1. Open the notebook `Lunar_Martian_Seismic_Activity_Prediction.ipynb` in Google Colab or locally.
2. Run all cells to simulate seismic data, train the LSTM model, and visualize predictions.
3. Modify sequence length, epochs, or data parameters as needed.

## Future Work
- Replace simulated data with real **Apollo lunar** or **InSight Marsquake** datasets.
- Enhance model architecture with more layers or CNN-LSTM hybrid.
- Implement more advanced event detection and alert systems.
